# 馆际作品借展

处理复合作品信息、借展约束、状态交接与策展引用。

`fixtures/domain.json` 保存首批领域名词和状态样例，便于接口联调时保持一致语义。运行 `python3 service.py --check` 可检查基础配置；执行 `npm test` 可验证健康入口与全部领域契约。

## 模型分层

- `domain.py` — 领域核心（仅标准库）：
  - `Work` / `Segment` / `Contribution`：作品实体、组成区段、作者贡献（合作顺序、题跋等挂到具体区段）；
  - `Agreement`：展期、展厅、照度、运输、保险、数字传播用途；改期通过版本链（`supersedes`）保留旧条款；
  - `Handover` / `ConditionReport` / `Incident`：出库、到馆、布展、撤展、归还五类交接，双方签认；
  - `LabelVersion`：展签版本，发布即锁定证据快照。
- `service.py` — HTTP 编解码与状态码映射，规则全部委托给 `domain.py`；可用 `--state-file`（或环境变量 `LOAN_STATE_FILE`）指定状态快照文件，变更原子落盘，重启后继续交接。
- `domain_contract.py` — 业务规则的可执行契约（含事故解除回归用例）。

## 关键规则

1. **复合作品结构**：普通藏品表的一行作品之外，区段（引首/画心/尾纸题跋）与作者贡献（作画/题跋/书引首/鉴藏印/题签，含合作顺序）分别登记；贡献必须指向已登记的区段，合作顺序不得重复。
2. **协议约束**：展期起止、展厅、照度上限（勒克斯）、运输方式、保险（如钉到钉）、数字传播用途随协议保存；跨馆改期生成新版本并保留旧版，当前授权永远取最新版。
3. **交接签认**：五类交接按固定生命周期顺序办理，交出方与接收方角色固定（如出库 = 出借馆 → 运输方），缺签认人或角色不符一律拒绝。
4. **重复扫码幂等**：扫码标识全局唯一；重复扫码返回 `409` 且不产生第二条记录，被拒绝的扫码不会被消费；重启后扫码记录仍然保留。
5. **损伤冻结**：状态报告记为“损伤”时立即冻结该作品的全部后续交接，登记损伤事件（一次交接可在 `damage_items` 中登记多处损伤，每处独立立案）并保全损伤前/后图像哈希（sha256）。**冻结不是单独写入的开关，而由“是否仍有未解除事故”派生：作品只有在全部事故关闭后才恢复交接**，任一事故仍开放时后续交接一律 `409`。
6. **事故解除**：`POST /incidents/{id}/resolve` 必须携带解除编号 `resolution_id`、处理人 `resolver`、复核结论 `resolution_note`、证据摘要 `evidence_summary`（缺一返回 `400`）。语义：
   - 对已解除事故的**完全重放**（编号与处理人/结论/摘要完全一致）返回原结果（`replayed: true`），但不再写入、不解冻、不改变任何当前状态——复损后重放第一次解除不会放行归还；
   - 同一解除编号内容变化，或已解除事故又收到别的编号（迟到旧请求），返回 `409`；
   - 解除编号全局唯一，不能跨事故复用；并发解除同一事故时恰好一次真正生效，其余为幂等重放（领域写操作经锁串行化）；
   - 旧数据中已解除但缺少解除标识的记录，加载时按 `legacy-resolution:<incident_id>` 确定性补齐，冻结仍由事故状态重新派生。
7. **一致的风险展示**：风险查询（`/risk`）、作品视图、展签证据快照与解除响应都展示该作品**全部历史事故**（开放与已解除，及解除处理人/结论/证据）与**当前冻结原因** `frozen_reason`；展签快照在发布时整体固化，之后状态变化不回写旧版。
8. **展签快照**：发布日期确认后锁定证据快照（作品、区段、十六位作者贡献、当时协议版本、交接记录、保管状态、全部事故历史与未解除风险）；之后的学术更正或改期只产生新版展签，旧版展签与其快照永不改变。
9. **争议追溯**：`/works/{id}/segments/{sid}` 从争议区段直达实体、该区段上的作者贡献、当前保管责任与相关损伤事件；`/works/{id}/risk` 汇总保管、授权范围与未解除风险。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 服务身份健康检查 |
| POST | `/works` | 登记作品（可含区段与贡献） |
| GET | `/works/{id}` | 作品视图（结构、当前协议、保管状态、冻结标记） |
| GET | `/works/{id}/risk` | 当前保管责任、授权范围、未解除风险 |
| GET | `/works/{id}/segments/{sid}` | 局部状态争议定位 |
| POST | `/agreements` | 订立借展协议 |
| POST | `/agreements/{id}/reschedule` | 跨馆改期/改条款，生成新版本 |
| POST | `/handovers` | 办理一次双方签认交接 |
| POST | `/incidents/{id}/resolve` | 损伤复核解除（编号/处理人/结论/证据摘要，幂等）；全部事故关闭后恢复交接 |
| POST | `/works/{id}/labels` | 起草展签 |
| POST | `/works/{id}/labels/publish` | 确认发布日期并锁定快照 |
| POST | `/works/{id}/labels/correct` | 学术更正，另起新版 |
| GET | `/works/{id}/labels` / `.../labels/{v}` | 读取最新版或指定旧版展签 |

规则违反返回 `400`（数据不合法）或 `409`（重复扫码、跳步交接、已冻结、已锁定等状态冲突），响应体为 `{"error": "..."}`。

## 本地运行

```bash
python3 service.py --check      # 自检
npm test                        # service_contract + api_contract + domain_contract
python3 service.py --port 8000  # 启动 HTTP 服务
python3 service.py --state-file ./loan-state.json  # 启用状态快照，重启不丢交接/冻结/解除记录
```
